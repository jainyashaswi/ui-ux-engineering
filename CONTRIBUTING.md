# Contributing to `ui-ux-engineering`

Contributions that add concrete, testable UI/UX rules, accessibility checks, or component playbooks are welcome.

## Guidelines
1. **Concrete over vague:** Every rule should include a measurable threshold (e.g., `48px` target, `<250ms` duration, `4.5:1` contrast) or a clear ❌ Before / ✅ After contrast.
2. **Visuals:** Place new reference screenshots in `references/screenshots/` and link them using relative paths (`screenshots/<filename>.jpg`) in `references/playbook.md`.
3. **Keep `SKILL.md` concise:** Detailed examples and catalogs belong in `references/`, not `SKILL.md`.
